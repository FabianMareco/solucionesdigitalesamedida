# Soluciones Digitales a Medida

Sitio de Fabián Mareco, servido con Next.js.

Los archivos de `public/` son los originales del borrador (HTML, CSS, JS de motion, fuentes e imágenes), sin modificar.
Next.js los sirve y mapea las rutas:

- `/` → `public/index.html`
- `/servicios` → `public/servicios.html`

## Desarrollo

```bash
npm install
npm run dev
```

## Deploy en Vercel

Importar este repositorio en Vercel (framework: Next.js, sin configuración extra).
